## Optipan. Proyecto Final Maven-Openxava

Optipan, es un proyecto de Test y Validación de Software, que
por medio de una plantilla en Maven de open-xava, donde ponemos
en practica, e implementación, de practicas de pruebas y casos de 
prueba.

Probamos la implementación de un algoritmo de calculo de precio de
la harina según la capacidad de peso dentro la aplicación.

# Stack Tecnológico
- **Framework:** [OpenXava X.X.X]
- **Lenguaje:** [Java 17/21]
- **Base de Datos:** [PostgreSQL / H2 / MySQL]
- **Build Tool:** [Maven / Gradle]

## 📋 Requisitos Previos
Para ejecutar este proyecto, necesitas tener instalado:
- [JDK 17 o superior] - [Tu gestor de dependencias, ej. Apache Maven]
- [IDE recomendado: Eclipse / IntelliJ IDEA / VS Code]
